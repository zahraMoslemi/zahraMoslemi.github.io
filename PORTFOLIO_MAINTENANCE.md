# Zahra Moslemi's research portfolio

The homepage, publications, and CV pages use a custom academic design inspired by
Sherry Tongshuang Wu’s compact profile and thematic research organization
(https://www.cs.cmu.edu/~sherryw/). The code and illustrations are original. Existing
GitHub Pages/Jekyll deployment is retained. Generated HTML is checked in so no new
build service, JavaScript framework, or package installation is required.

## Updating the site

1. Edit the publication records or page copy in `scripts/build_portfolio.py`.
2. No CV file is published (removed October 16, 2026); the `/cv/` page is a text summary only.
3. If changing the conceptual illustrations, edit and run
   `python3 scripts/build_portfolio_visuals.py`. These SVGs are schematics, not
   experimental figures or reported results.
4. Run `python3 scripts/build_portfolio.py`.
5. Preview with `python3 -m http.server 8765 --bind 127.0.0.1 --directory _portfolio_preview`.
6. Review changes before publishing through the existing GitHub Pages branch.

The preview contains the exact HTML bodies, CSS, JavaScript, image, and CV used by
the three pages. Jekyll front matter supplies their public routes. The preview
directory and maintenance scripts are excluded from the public build.

The legacy AcademicPages sample posts, publications, talks, teaching entries,
and demonstration pages are excluded in `_config.yml`; their sources are retained.

## Paper figures and figure viewer (October 16, 2026)

- Every paper card shows a figure. Seven are original method diagrams generated by
  `scripts/paper_figures.py` (SVG, 1700×900) in the visual language of the MGMT
  architecture figure: numbered stages, dashed rule panels, light-blue operation
  boxes, stage brackets. They summarise each paper's method and are not copies of
  journal figures. The MGMT preprint keeps its real Figure 1 from the TMLR
  submission source (`mgmt-architecture*.png`) plus two result figures.
- Clicking a card or its "Figure" link opens a viewer (`<dialog>` in
  `assets/js/portfolio.js`) with the full-size figure and a caption. The three
  research-direction cards are matching 16:9 illustrations (`theme-*.svg`).
- Figure records (file, size, alt text, one-line lead, caption) live in `FIGURES`
  in `scripts/build_portfolio.py`. Designed figures use the same SVG for card and
  viewer (`object-fit: contain`); raster figures use a 900×506 `-card` crop.
- To change a designed figure: edit its function in `scripts/paper_figures.py`,
  run `python3 scripts/paper_figures.py`, then `python3 scripts/build_portfolio.py`.
  Preview SVGs locally with `qlmanage -t -s 1700 -o /tmp file.svg` or in a browser.
- Sources used for the content of each diagram: SCOPE arXiv:2610.17146; FBNN
  arXiv:2312.11799; MGMT workshop paper (OpenReview CBcubwXMhA) and arXiv:2601.22593;
  POLARIS arXiv:2601.11816; AEMA arXiv:2601.11903; STRONG (Stroke 2024, PubMed
  38979623 abstract); OCT (WJARR 2024, CC BY 4.0 full text).
- `images/research/*.svg` from `scripts/build_portfolio_visuals.py` are no longer
  referenced by the pages but are kept for reference.
